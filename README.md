## 📋 About

CaseFlux é uma ferramenta web para converter textos em diferentes formatos de capitalização e montar nomes de arquivo no padrão `Autor - Título`.

O projeto foi desenvolvido como uma aplicação estática, sem dependências de build ou instalação. Basta abrir o arquivo `index.html` em um navegador moderno.

## ✨ Features

- Converter textos para:
  - minúsculas
  - MAIÚSCULAS
  - Frase
  - Título
  - camelCase
  - PascalCase
  - snake_case
  - kebab-case
  - CONSTANT_CASE
  - dot.case
  - aLtErNaDo
- Copiar resultados com um clique.
- Aplicar um formato diretamente ao texto original.
- Contar palavras e caracteres.
- Gerar nomes de arquivo a partir de autor e título.
- Limpar automaticamente separadores e espaços repetidos.
- Usar “Autor Desconhecido” quando o autor não for informado.
- Inverter a ordem entre autor e título.
- Remover caracteres inválidos para nomes de arquivo.
- Alternar entre tema claro e escuro.
- Personalizar palavras menores usadas em títulos.

## 💻 Getting Started

### Abrir diretamente

Abra o arquivo `index.html` em qualquer navegador moderno.

### Executar um servidor local

No diretório do projeto, execute:

```bash
python -m http.server 8000
```

Depois, acesse [http://localhost:8000](http://localhost:8000).
